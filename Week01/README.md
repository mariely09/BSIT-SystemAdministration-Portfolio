# Challenges Encountered
1. Git was not recognized in the command prompt. After installing, the `git` command showed "'git' is not recognized as an internal or external command." I solved this by reinstalling Git, making sure the option to add Git to the system PATH was selected, and then restarting the terminal.

2. GitHub verification email did not arrive. At first, the verification email never appeared in my inbox. I checked the Spam folder, requested a new verification email from GitHub settings, and was able to verify my account successfully.

3. VirtualBox warned that hardware virtualization was disabled. During setup, the installer showed an error about virtualization being turned off. I restarted my computer, entered the BIOS/UEFI settings, enabled Intel VT-x / AMD-V, and after saving the changes the installation completed successfully.

# Reflection
This week's activity taught me how important it is to have a properly configured professional environment in the field of system administration. Installing tools like Git and Visual Studio Code taught me to pay attention to system requirements, installation options, and configuration settings such as PATH variables. These are things a system administrator must always check.

I also learned the basics of version control. Git and GitHub showed me how changes can be tracked, organized, and shared, which is essential not only in programming but also in managing system configurations, scripts, and documentation. Creating my GitHub and LinkedIn accounts also made me realize that professionalism extends beyond the technical side. Building an online identity is part of growing in the IT industry.

The challenges I encountered, such as installation errors and account verification issues, trained my patience and improved my troubleshooting skills. I realized that most problems can be solved by reading error messages carefully, checking the official documentation, and not being afraid to try again.

These tools will greatly support my growth as a future System Administrator. Visual Studio Code will be my main editor for scripts and configuration files, Git will help me manage and track changes to my work, and GitHub will serve as my portfolio and collaboration platform. The discipline of documenting every step of this activity is the same discipline required of system administrators when maintaining servers and networks.

Overall, this activity gave me not only technical skills but also the mindset of a professional who is organized, resourceful, and always learning.
